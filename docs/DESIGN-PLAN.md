# خُطَّة إعادَة التَّصميم — مَنصَّة ACommerce V1

> الهَدَف: تَصميم احتِرافيّ قابِل لِلبَيع ($200+/شَهر) — لا أَخطاء قَواعِدِيَّة
> فَحَسب، بَل تَخطيط وشَكل ووِدجِتس تُرضي العَين.
>
> المَنهَجِيَّة (مُتَّفَق عَلَيها): **(١)** تَخطيط كُلّ الصَّفحات → **(٢)** تَخطيط
> الوِدجِتس والتَّنسيقات → **(٣)** التَّنفيذ على **عِدَّة جَولات**.
>
> **التَّصميم مُتَجاوِب (responsive) عَبر مُختَلِف الشّاشات** — موبايل وتابلت
> وسَطح مَكتَب. لا تَصميم لِجِهاز واحِد.
>
> المَبدَأ الأَساس: الصَّفحات مَبنِيَّة مِن وِدجِتس. نُعيد تَصميم الوِدجِتس
> فَتَرتَفِع كُلّ الصَّفحات. الصَّفحات «مُتَشابِهَة إلّا لِلضَّرورَة» — نُصَنِّفها
> إلى **أَنماط (archetypes)** ونُصَمِّم النَّمَط لا الصَّفحَة الفَرديَّة.

## الجُزء أ — لُغَة التَّصميم (الإحساس)

| العُنصُر | القَرار |
|---|---|
| الشّاشات | **مُتَجاوِب**: موبايل ≤640، تابلت 641–1024، سَطح ≥1024. CSS مَبنيّ موبايل-أَوَّلاً ثُمَّ `@media (min-width)` يُوَسِّع. الشَّبَكات: عَمود → عَمودان → ٣–٤ أَعمِدَة. |
| اللَون | **لَون واحِد لِكُلّ مَتجَر** (`--ac-primary`) → تِنتات + تَدَرُّج. لا palette ثابِت. الباقي: أَسطُح دافِئَة + نَصّ slate. |
| العُمق | ظِلال مُتَعَدِّدَة الطَّبَقات (`--ac-shadow-sm/md/lg`) + ظِلّ مُلَوَّن لِلـ CTA |
| الطِّباعَة | Cairo. عَرض (display) 28–40، عَناوين 20–24 وَزن 800، نَصّ 14–16، مُساعِد 12–13 |
| الإيقاع | شَبَكَة 4-نِقاط. حَشو البِطاقات 16/20. فَجَوات الأَقسام 24–28 |
| الحَرَكَة | hover lift، spring على الأَيقونات، transitions 180ms |
| الزَّوايا | 10/14/18/24 — البِطاقات 18 |
| الحالات الفارِغَة | أَيقونَة كَبيرَة في دائِرَة لَونِيَّة + عُنوان + وَصف + CTA |
| الصُّوَر | نِسبَة ثابِتَة + placeholder تَدَرُّجيّ بِأَيقونَة (لا رَماديّ مَيِّت) |

الأَساس مُنَفَّذ في `premium.css` (tokens العُمق/اللَون/الطِّباعَة/الحَرَكَة).

## الجُزء ب — تَخطيط الصَّفحات (٢٩ صَفحَة → ٨ أَنماط)

### النَّمَط ١ — Feed (شَبَكَة بِطاقات)
**الصَّفحات:** TenantHome (دَور عَميل)، TenantExplore، Favorites، MyListings،
TenantDrivers
**التَّخطيط الجَديد (مِن أَعلى لِأَسفَل):**
```
[TopNav زُجاجيّ + شِعار + جَرَس]
[Hero مُصَغَّر: عُنوان عَرض + سَطر قيمَة + AcSearchBox بارِز]   ← جَديد
[AcFilterBar أُفُقيّ scroll: رُقَع تَصنيف + فَرز + تَبديل عَرض]
[شَريط نَتائِج: «N نَتيجَة» + حِفظ بَحث]
[شَبَكَة AcSpaceCard — بِطاقَة بِصورَة 16:10 + شارَة + قَلب + سِعر بارِز]
[BottomNav مُرتَفِع + مُؤَشِّر نَشِط]
```

### النَّمَط ٢ — Detail (تَفصيل)
**الصَّفحات:** TenantListingDetail، MyDealDetail، VendorProfile
```
[AcGallery حافَّة-لِحافَّة + أَزرار رُجوع/مُفَضَّلَة عائِمَة]
[كُتلَة العُنوان: عُنوان عَرض + مَوقِع + سِعر كَبير]
[AcStatsGrid: مُشاهَدات/سَعَة/تَقييم]   ← شَريط حَقائِق
[أَقسام بِطاقات: الوَصف، الخَصائِص (AcAttrGrid)، المَوقِع (خَريطَة)، البائِع]
[AcStickyActionBar سُفليّ: سِعر + «تَواصَل» / «احجِز»]   ← ثابِت
```

### النَّمَط ٣ — Inbox (قائِمَة صُفوف غَنِيَّة)
**الصَّفحات:** Chats، Notifications، MyDeals، MyOffers، MySearches
```
[AcPageHeader: عُنوان + إجراء]
[AcSegmentControl اختياريّ: الكُلّ/غَير مَقروء]
[قائِمَة AcListRow — صورَة/أَفاتار + عُنوان + مُعايَنَة + وَقت + شارَة عَدّ]  ← وِدجِت جَديد
[حالَة فارِغَة عِندَ لا بَيانات]
```

### النَّمَط ٤ — Conversation (مُحادَثَة)
**الصَّفحة:** ChatRoom
```
[رَأس: أَفاتار الطَّرَف + اسم + حالَة]
[خَيط فُقّاعات AcChatBubble — يَمين/يَسار + وَقت + مَقروء]  ← وِدجِت جَديد
[Composer ثابِت سُفليّ: حَقل + إرفاق + إرسال]
```

### النَّمَط ٥ — Form (نَموذَج)
**الصَّفحات:** CreateListing، ProfileEdit، Checkout، Login، RoleOnboarding،
RolePicker
```
[AcPageHeader أو Hero مُصَغَّر]
[خَطوات/أَقسام في AcCard — كُلّ قِسم عُنوان + AcField + AcInput]
[رَفع صُوَر بِمُعايَنَة مُصَغَّرَة]
[AcStickyActionBar: زِرّ أَساسيّ كامِل العَرض]
```

### النَّمَط ٦ — Dashboard (لَوحَة دَور)
**الصَّفحات:** TenantHome (دَور host/vendor/driver/rider عَبر RoleHome)
```
[Hero تَدَرُّجيّ: تَحِيَّة + اسم المُستَخدِم + شارَة الدَّور]   ← جَديد
[AcCtaCard أساسيّ كَبير (إعلان جَديد / اطلُب مِشوار)]
[AcStatsGrid: ٣ إحصاءات في بِطاقات]
[AcSectionHeader + قائِمَة عَناصِر حَديثَة]
```

### النَّمَط ٧ — Entry (دُخول/اختِيار)
**الصَّفحات:** Landing، RoleLanding، Plans
```
[Hero مِش تَدَرُّجيّ + علامَة زُجاجِيَّة + عُنوان عَرض + قيمَة]
[شَبَكَة بِطاقات اختِيار (دَور / باقَة) — أَيقونَة + عُنوان + وَصف + سِعر + CTA]
```

### النَّمَط ٨ — Document (مُحتَوى نَصّيّ)
**الصَّفحات:** Terms، LegalHub، Support، DriverArea
```
[AcPageHeader]
[بِطاقَة مُحتَوى بِطِباعَة مَقروءَة + عَناوين + قَوائِم]
[Support: + نَموذَج تَذكَرَة]
```

## الجُزء ب٢ — صَفحات المَنصَّة (admin / studio / app-admin)

> لَيسَت صَفحات عَميل، لكِنَّها جُزء مِن المُنتَج المَبيع — يَجِب أَن تَكون
> ضِمن نَفس لُغَة التَّصميم.

### أ) ادمن المَنصَّة `/admin/*`
AdminHome، CreateTenant، AuditLogPage، QualityMonitor، AgentChat،
IncubatorHome/Wizard/Study، IncubatorFixtures.
**النَّمَط:** Dashboard إداريّ — `AcPageHeader` + `AcStatsGrid` + جَداوِل/صُفوف
نَظيفَة (`AcListRow`) + إجراءات. لا زَخرَفَة.

### ب) رائِد الأَعمال `/studio/*` (StudioShell)
StudioHome، StudioApp(+branding/categories/regions/roles/console/deals/
tickets)، StudioBilling، StudioNewIdea، StudioStudy.
**النَّمَط:** Shell جانِبيّ + مُحتَوى. بِطاقات إحصاء + قَوائِم + مُحَرِّرات.

### ج) ادمن التَّطبيق `/admin/tenants/{slug}/*`
TenantEdit، TenantBranding، TenantCategories، **TenantRegions**،
**TenantAttributes**، TenantRoles، TenantUsers، TenantPwa.
**النَّمَط:** نَماذِج تَكوين — `AcPageHeader` + أَقسام بِطاقات + **مُحَرِّرات
مُهَيكَلَة** (لا نَصّ خام).

### ⛔ قاعِدَة إلزامِيَّة — مَوت مُربَّع النَّصّ بِفَواصِل
المُحَرِّرات الحاليَّة تَستَخدِم `textarea` بِفَواصِل (`المَدينَة > حَيّ،حَيّ`
و`Code | Name | Type | req | val=label`). **هذا مَمنوع** — صيغَة مُطَوِّرين
لا تَليق بِعَميل. تُستَبدَل بِـ:
| المُحَرِّر | الواجِهَة المُهَيكَلَة الجَديدَة |
|---|---|
| **المُدُن/الأَحياء** (TenantRegions) | بِطاقَة لِكُلّ مَدينَة: حَقل اسم + **مُدخَل رُقَع (chip input)** لِلأَحياء + زِرّ حَذف. «+ مَدينَة». |
| **الخَصائِص** (TenantAttributes) | بِطاقَة لِكُلّ حَقل: Code + الاسم + قائِمَة Type + مِفتاح «مَطلوب» + (لِلاختِيار) مُحَرِّر خِيارات بِرُقَع. «+ حَقل». |
| **الفِئات** (TenantCategories) | صَفّ لِكُلّ فِئَة: slug + تَسمِيَة + أَيقونَة + قائِمَة kind. «+ فِئَة». |
**التَّقنِيَة:** تَحسين تَدريجيّ — واجِهَة مُهَيكَلَة + JS يُسَلسِل إلى الحَقل
المَخفيّ بِالصيغَة الَّتي يَفهَمُها الـ endpoint الحاليّ (صِفر تَغيير خَلفيّ).
وِدجِت جَديد: **AcChipInput** + **AcRepeatRows**.

## و. خُطَّة التَّنفيذ المُتَبَقِّيَة (مُرَتَّبَة)
